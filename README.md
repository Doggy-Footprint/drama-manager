# bunkerkids

- `src/park/`: **데모 3. 공원 데이트 RP** (월드 모델, 떡밥, 드라마 매니저, 캐릭터). 아래 참고.
- `src/chat/`: 터미널 채팅 인터페이스(데모 2에서 떼어 냄).
- `demo-1/`, `demo-2/`: 실패한 시도(아카이브). 데모 2의 교훈은 `demo-2/from_v2.md`.

## 데모 3 실행

```bash
PYTHONPATH=src .venv/bin/python -m park        # http://127.0.0.1:8765 시연 화면
.venv/bin/python -m pytest -q
```

`.env`에 `OPENAI_API_KEY`가 필요하다. 모델은 `RP_MODEL`(기본 `gpt-6-luna`. `gpt-6.1-luna`는 이 키로 404),
드라마 매니저 추론 강도는 `RP_DM_EFFORT`(기본 `low`, 턴당 약 15초. `medium`은 판단이 조금 깊지만 턴당 20~35초).
턴마다의 판단 전체는 `runs/park/<시각>.jsonl`에 남고, 화면 헤더의 로그 선택(또는 `/?run=<파일>`)으로 읽기 전용으로 다시 볼 수 있다.

터미널에서도 같은 로그를 남기며 진행할 수 있다(에이전트끼리 시험할 때 쓴다).

```bash
PYTHONPATH=src .venv/bin/python -m park.cli new 이름 [--baseline]   # 새 세션 + 시작 턴. 로그는 runs/park/<시각>_<이름>.jsonl
PYTHONPATH=src .venv/bin/python -m park.cli say 이름 "말 (행동)"     # 한 턴. 기본은 유저에게 보이는 것만, --verbose면 DM 판단까지
PYTHONPATH=src .venv/bin/python -m park.cli log 이름
```

## 한 턴의 흐름

```
유저 입력
 ├─ 월드 검색기 ──┐  (병렬, LLM retriever) 이벤트: 코드가 장소·시간 창으로 먼저 거른 후보에서 고른다.
 │                │   장면 사실: 대화에서 정해진 사실(남은 자리, 소지품 등) 중 지금 걸리는 것을 고른다.
 ├─ 떡밥 검색기 ──┤  지금 필요한 "쓸모"를 먼저 정하고 그 쓸모를 가진 떡밥을 고른다. 최근 3턴 안에 실제로 쓰인 떡밥은 코드가 뺀다.
 ├─ 사실 추출기 ──┤  지난 턴 수아의 말 + 이번 유저 입력에서 새로 생긴 장소·사실·과거를 뽑는다.
 │                ▼
 ├─ 드라마 매니저: 흐른 시간, 위치, 채널(마주/전화/닿지 않음), 떨어진 동안 수아가 한 일,
 │                박자·긴장, 이벤트, 떡밥(plant/mention/payoff, 수아에게 or 지문으로), 비밀 열기,
 │                수아의 속마음(directive), 특성·목표 갱신, 추출된 사실 판정(쓸모가 있으면 떡밥 풀에도),
 │                수아에게 보일 사실 선택, 지난 사실 정리
 ├─ 코드 검증·반영: 시간·배터리는 앞으로만(시작 턴 0분), 이벤트는 한 번·시간 창 안, 핵심 이벤트는 강제,
 │                함께 있던 수아를 DM이 혼자 보내지 못함, 폰이 꺼지면 전화가 안 닿음, 세계 확장 시 20% 이벤트,
 │                검색 후보가 아닌 이벤트·떡밥·사실은 거절
 ├─ 캐릭터(수아): 선별된 정보만 담긴 XML을 받고 말한다. 혼자 자리를 뜰 수 있다(move.alone).
 │                실제로 쓴 떡밥(used_details)만 상태가 바뀐다. 고르기만 하고 안 쓴 떡밥은 "시도"로 남는다.
 └─ 10턴마다 DM이 원문 턴 중 끝난 덩어리를 에피소드로 묶는다(최근 5턴은 원문 유지)
```

화면의 대화 턴마다 그 턴의 LLM 호출 수·입력 토큰·KV 캐시 적중률·출력 토큰이, 헤더에 세션 누적(기준선 호출은 따로)이 보인다.

- 데이터: `src/park/data/world.yaml`(장소·인파·이벤트·배터리), `details.yaml`(떡밥과 쓸모), `character.yaml`(수아. core/dynamic, 서운함, 목표, 비밀 cover/fact).
- 비밀: `hinted`는 수아가 알지만 `locked` 동안 말하지 못한다. `buried`는 열리기 전엔 수아에게 fact가 보이지 않는다. DM이 열면 `revealable`이 되고, 털어놓을지는 수아가 정한다.
- 프롬프트: `src/park/prompts/`.
- 기준선: 화면의 "기준선 함께 보기"를 켜면 같은 유저 입력을 캐릭터 프롬프트만 가진 수아(`prompts/baseline.md`)에게도 보내 나란히 보여 준다.
